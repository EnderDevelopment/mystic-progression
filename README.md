# Mystic Progression

Mystic Progression is a Minecraft plugin that enhances your gameplay with RPG elements, including skill progression, talent trees, and magic. It allows players to upgrade their skills, unlock new abilities, and explore magical powers, creating a rich and immersive role-playing experience.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/MysticProgression/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. Join your Minecraft server.
2. Use the `/rpg` command to access the RPG menu.
3. Navigate through the skill trees to upgrade your abilities.
4. Explore and unlock magical powers to enhance your gameplay.
